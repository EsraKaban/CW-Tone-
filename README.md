# Continuous Wave (CW) Tone Generator

Proyek ini berisi implementasi pembangkit sinyal **Continuous Wave (CW) Tone** (gelombang sinusoidal murni dengan frekuensi dan amplitudo konstan) untuk keperluan pengujian sistem RF, kalibrasi instrumen ukur, karakterisasi *mixer*/penguat, serta simulasi pemrosesan sinyal.

## 📋 Deskripsi Singkat

Sinyal CW *tone* merupakan sinyal dasar berupa gelombang sinus atau kosinus kompleks
